# MediTrack – Medicine Schedule & Stock Reminder

> 💊 Student Project | RJ1P24K · 1A19

A web-based medicine schedule and stock reminder application built with HTML, CSS, and JavaScript.

## Features
- Dashboard with live clock & animated background
- Medicine schedule with dose status tracking
- Real-time alerts for missed doses & low stock
- Add / Edit / Delete medicines
- Dose history log
- Persistent storage (localStorage)

## Live Demo
🌐 Deployed via GitHub Pages

## Run Locally
Just open `index.html` in any browser.

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- Chart.js for data visualization
- LocalStorage for data persistence
